## Project Layout

- `website/` - Game promotional website assets.
- `Config/` - Unreal Engine project configuration.
- `Content/` - Unreal Engine game assets and maps.
- `Source/` - C++ game source code.
- `Build/` - Project build metadata and platform files.
- `our.uproject` - Unreal Engine project descriptor.

# Fragments of Aether

This repository contains the Unreal Engine project files for **Fragments of Aether**.

## Promotional Website

The game promotional website is available at:

https://hogomex393-svg.github.io/Fragments-of-Aether/

Website files are organized in the `website/` folder.

## Project Layout

- `website/` - Game promotional website assets.
- `Config/` - Unreal Engine project configuration.
- `Content/` - Unreal Engine game assets and maps.
- `Source/` - C++ game source code.
- `Build/` - Project build metadata and platform files.
- `our.uproject` - Unreal Engine project descriptor.
